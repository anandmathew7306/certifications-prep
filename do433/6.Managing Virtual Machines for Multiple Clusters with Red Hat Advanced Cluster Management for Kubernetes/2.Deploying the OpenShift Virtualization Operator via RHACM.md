# 6.3 Deploying the OpenShift Virtualization Operator via RHACM

- Manual per-cluster operator installs don't scale — RHACM automates/enforces consistent installs fleet-wide, via **GitOps** or **policies**.
- Core building blocks recap: **ClusterSet** (logical grouping for targeting), **GitOps/Argo CD** (Git = source of truth), **Push vs Pull models** (hub-deploys vs cluster-pulls).
- **Argo CD Sync Waves** (`argocd.argoproj.io/sync-wave` annotation) control deployment order — lower numbers apply first (default wave = 0 if unannotated). For OpenShift Virtualization: `OperatorGroup` (wave 1) → `Subscription` (wave 2) → `HyperConverged` CR (wave 3, the CR that actually activates the operator — an empty `spec: {}` installs with defaults).
- **GitOps deployment flow**: prepare a Git repo (e.g. `openshift-virtualization/operator/`) with OperatorGroup/Subscription/HyperConverged manifests targeting the `openshift-cnv` namespace → in RHACM console: Applications → Create application → *ApplicationSet - Push model* → set name/Argo server → Git repo/branch/path/remote namespace → Placement → submit. Argo CD applies resources in sync-wave order.
- **Policy-based deployment (alternative)**: use the built-in **`OperatorPolicy`** template (Governance → Policies → Create Policy → Install an operator) to declare installation namespace, subscription details (name, channel, source, starting CSV, allowed versions), and `remediationAction: enforce`. A **separate `ConfigurationPolicy`** creates the `HyperConverged` CR, using a policy **`dependencies`** entry so it only runs once the operator-install policy is `Compliant`.
- **Verification**: via RHACM console (green status on the Application, or on both the operator-install and HyperConverged policies), via CLI (`oc get pods -n openshift-cnv` for `hco-operator-`/`virt-api-`/`virt-controller-`/`virt-handler-` pods; `oc get hco -n openshift-cnv kubevirt-hyperconverged -o yaml` checking `Available`/`ReconcileComplete`), or via the OpenShift console (Operators → Installed Operators → openshift-cnv project).
