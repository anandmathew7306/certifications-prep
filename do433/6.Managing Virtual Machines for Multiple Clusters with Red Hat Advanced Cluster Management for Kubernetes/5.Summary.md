# Key takeaway (6.10 Summary)

RHACM extends Kubernetes management to VM workloads. The operator itself is deployed fleet-wide via GitOps (Argo CD + sync waves) or governance policies (with policy dependencies ensuring order); actual VMs are then deployed/managed the same way, through `ApplicationSet`+`Placement`. RHACM's observability stack adds virtualization-specific Grafana dashboards (fleet, per-cluster, per-VM, inventory, time-in-status) plus right-sizing recommendations, rounding out lifecycle + monitoring for VMs across the whole managed fleet.
