# 2.3 Navigating the RHACM Web Console

- RHACM console is a **plug-in on top of the OpenShift console** — access it via the cluster switcher → **All Clusters**.
- Nav panel: **Home** (Welcome + Overview), **Infrastructure** (Clusters/Automation/Host inventory/VMs), **Applications** (GitOps/Argo CD-based), **Governance** (policies), **Credentials** (stored connection info for cloud/data-center/automation providers).
- **Search**: indexes/relates Kubernetes objects fleet-wide.
  - Architecture: **Collector** (per-cluster, gathers objects via K8s API) → **Indexer** (hub-only, writes to Postgres) → **Database** (Postgres) → **Search API** (enforces per-cluster RBAC on results).
  - Free-text search, refinable with filters (`kind:`, `label:`, etc.); numeric filters (`cpu`, `replicas`, `capacity`, `memory`) support arithmetic comparators (e.g. `<3`).
  - Not every field is indexed (e.g. Deployment's `.spec.strategy` isn't searchable). Labels *are* always indexed — label your objects for better search.
  - Configurable: PVC-backed Postgres storage, CPU/memory limits for collector/indexer, saved-query limit (default 10, via `SAVED_SEARCH_LIMIT`), and custom search templates (`console-search-config` ConfigMap).
