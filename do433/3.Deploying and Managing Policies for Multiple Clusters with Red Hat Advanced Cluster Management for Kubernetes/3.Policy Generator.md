# 3.5 Policy Generator

- The **Policy Generator** auto-builds Policy/Placement/PlacementBinding YAML from plain K8s manifests — ships with the RHACM subscription.
- Two ways to run it: as a **Kustomize plugin** (binary placed under `~/.config/kustomize/plugin/...`, invoked via `kubectl kustomize --enable-alpha-plugins <dir>`), or as the **standalone `PolicyGenerator` CLI** (`PolicyGenerator <file>.yaml`) — course focuses on the standalone tool.
- Config file (`kind: PolicyGenerator`) has: `policyDefaults` (shared settings — severity, remediationAction, complianceType, namespace) + mandatory `policies:` list (each referencing manifest file(s)/dir) + optional `policySets:`/`policySetDefaults:`.
- `complianceType`: `musthave` (default, object must exist matching spec) / `mustonlyhave` (exact match) / `mustnothave` (must be absent/deleted).
- Manifest files referenced by `policies` must live in a **separate directory** from the generator config (to avoid the generator wrapping itself).
- Output = ready-to-`oc apply` Policy + Placement + PlacementBinding YAML.
