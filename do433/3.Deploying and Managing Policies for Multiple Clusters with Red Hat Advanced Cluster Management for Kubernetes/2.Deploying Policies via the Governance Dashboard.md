# 3.3 Deploying Policies via the Governance Dashboard

- Dashboard tabs: **Overview** (compliance posture summary) · **Policy Sets** (group related policies) · **Policies** (main table — edit/enable/disable/enforce/delete via the ⋮ menu; Details + Results sub-tabs) · **Discovered Policies** (policies RHACM found controlling cluster behavior, even if not created via RHACM).
- Creating a policy: pick a template → edit via GUI or YAML → set Placement (choose cluster sets) → add standards/categories/controls as annotations → review → create.
- **Deleting a policy** removes the Policy but you must also clean up its `PlacementBinding` and `PlacementRule`/`Placement` (dashboard prompts for this; CLI needs 3 separate `oc delete`s).
- **`pruneObjectBehavior`** controls cleanup of resources the policy *managed* (not just the policy definition itself): `None` (default, manual cleanup) / `DeleteIfCreated` (delete only what the policy created) / `DeleteAll` (delete everything managed — use cautiously). Console only exposes this for Configuration Policies; others need YAML mode.
