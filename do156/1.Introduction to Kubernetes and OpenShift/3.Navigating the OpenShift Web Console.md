# 1.5 Navigating the OpenShift Web Console

- The web console is a browser GUI over the Kubernetes and OpenShift APIs. Everything is also doable via CLI.
- Find the console URL: log in with `oc login`, then run `oc whoami --show-console`.
- If several identity providers (IdPs) are set up, pick one on the login page first.
- Landing page depends on role: admins land on Overview, developers land on Add.
- Perspectives, switched from the top of the sidebar:
  - Administrator: cluster config, workloads, operations.
  - Developer: building and running apps.
  - Virtualization: managing VMs; appears only after the OpenShift Virtualization operator is installed.
- Administrator perspective:
  - Home -> Overview shows cluster status; Home -> Projects lists projects you can see.
  - Operators -> OperatorHub: find and install operators to add features.
  - Developer Catalog (per project): shared apps, services, event sources and S2I builders.
- Developer perspective:
  - Add page: create apps from the catalog, a Git repo or a container image.
  - Topology: visual map of apps, deployments, services and routes.
- Key terms:
  - Project: namespace plus extra settings for multitenancy (RBAC, network policies, quotas).
  - Operator: packaged app that extends the cluster.
  - Pod: smallest unit, one or more containers.
  - Deployment: manages a running app.
  - Route: exposes a service outside the cluster.
  - PV: a piece of storage, provisioned dynamically or by an admin.
  - PVC: a request that binds a PV into a namespace for pods to use.
