# 1.3 Red Hat OpenShift Components and Editions

- OpenShift adds a complete solution on top of Kubernetes:
  - Developer workflow: built-in image registry, CI/CD pipelines, and S2I (source-to-image builds).
  - Observability: monitoring and logging for both apps and the cluster.
  - Server management: install and update tooling for many platforms.
- Nodes run RHEL CoreOS: an immutable OS tuned for containers, same kernel and packages as RHEL, managed the Kubernetes way.
- Also adds a web console, unified tools and extra security. Existing Kubernetes skills and tools still apply.
- Try-out options (not for production): OpenShift Local (cluster on your laptop) and the Developer Sandbox (30 days free on a shared cluster).
- Managed vs self-managed:
  - Managed (on AWS, Azure, IBM Cloud, Google Cloud): Red Hat SRE runs and updates the cluster; less control (e.g. some auth options limited).
  - Self-managed (installers, on-prem or cloud): full control, but you own updates and fixes.
- Insights Advisor (Hybrid Cloud Console) uses data from the Insights Operator to flag cluster issues and suggest fixes.
- Editions, smallest to largest:
  - Virtualization Engine: VMs only (VM console, GitOps, monitoring, logging).
  - Kubernetes Engine: hardened Kubernetes on RHEL CoreOS, with OpenShift Virtualization and an admin console.
  - Container Platform: adds developer console, log and cost management, Serverless, Service Mesh, Pipelines, GitOps.
  - Platform Plus: adds Data Foundation, ACM, ACS and Quay.
- All editions share the same code base.
