# 3.5 Accessing and Managing Virtual Machines by Using the Web Console

- VM page: Virtualization -> VirtualMachines -> pick a VM. Tabs: Overview, Metrics, YAML, Configuration, Events, Console, Snapshots, Diagnostics.
- Configuration subtabs: Details (CPU/memory, boot order), Storage (disks, add ConfigMaps/secrets as disks), Network, Scheduling (node selectors, tolerations, affinity, migration strategy), SSH, Initial run (cloud-init or Sysprep), Metadata.
- State buttons: start, stop, restart, pause. Actions menu: clone, snapshot, compute or storage migration, copy SSH command, delete (stop the VM first).
- You can select several VMs and run an action on all of them at once.
- Hot-plug CPU/memory:
  - Only for template-based VMs.
  - Applied through a live migration, no reboot needed (Linux kernel 5.16+, Windows needs current viomem drivers).
  - Up to 4x the starting values; beyond that, or if migration fails, a restart is needed.
- Instance-type VMs: resize by changing the instance type (Details -> InstanceType); also applied by live migration.
- Change SSH keys later under Configuration -> SSH (remove, use existing, add new); needs RHEL 9+ and dynamic injection enabled at creation.
- Consoles:
  - VNC: Console tab; can paste guest credentials and send Ctrl+Alt+Del. "Open web console" on Overview gives a larger view.
  - Serial: choose it from the console drop-down; no key combos.
  - Desktop viewer (RDP) for Windows: needs an RDP client and the QEMU guest agent; disconnect VNC first.
