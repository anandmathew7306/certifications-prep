# 3.9 Monitoring and Inspecting Virtual Machines

- Monitoring is built on Prometheus; per-VM dashboards are in the web console.
- VM Overview tab:
  - Details card: name, status, created date, hostname, OS.
  - With the QEMU guest agent installed you also see logged-in users, file systems, and secondary networks; without it, only the OS chosen at creation.
  - Utilization card: CPU, memory, storage, network, with a selectable time range.
- Virtualization -> Overview: VM count and vCPU/memory/storage use, filterable by namespace. The Top consumers tab ranks VMs by resource use.
- The Metrics tab on a VM shows its CPU, memory, storage, and network graphs.
- Observe -> Dashboards -> "KubeVirt / Infrastructure Resources / Top Consumers" for cluster-wide views.
- CLI checks:
  - `oc logs <virt-launcher-pod>` for VM logs.
  - `oc get vm -n ns`, `oc get vm -A` for status.
  - `oc describe vm vm1 -n ns` for events and spec.
- `virsh` inside the `virt-launcher` pod (Terminal tab, or `oc exec`) is for admins doing low-level debugging, e.g. `virsh event <domain> --all`.
- `virtctl` reduces the need to enter the pod and works for non-admins too:
  - `virtctl fslist vmi1` lists guest file systems.
  - `virtctl guestosinfo vmi1` shows guest OS details from the guest agent.
