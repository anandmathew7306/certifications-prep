## What is a Node Pool?

A **node pool** = a logical group of compute (worker) nodes with similar hardware, grouped so workloads can be targeted to the right nodes.

**Why it matters:**
- Avoids wasting money running light workloads on expensive/high-CPU nodes.
- Avoids poor performance from running heavy workloads on weak nodes.
- Solves the **"noisy neighbor"** problem — isolate latency-sensitive apps onto their own pool so unrelated workloads don't degrade them.
- Common use: multi-tier hardware setups (e.g. `dev` / `staging` / `production` node pools).

**Key distinction (exam-relevant):**
| Cluster type | How pools are implemented |
|---|---|
| Standard OpenShift | Logical grouping via `MachineSet` + node **labels** (no dedicated API object) |
| Hosted Control Plane (HCP) | Dedicated `NodePool` API resource, replaces `MachineSet` |

## How Node Pools Are Built — Labels

Node pools are just **node labels**. Nothing more exotic than that.

```bash
# Add a node to a pool (label it)
oc label node/worker01 node-pool=gpu

# Verify the label landed
oc get nodes worker01 --show-labels

# Find all nodes in a given pool
oc get nodes --selector node-pool=gpu
```

## Gotchas (exam traps)

- If a label is applied via a `MachineSet` (not directly to the node), you must **redeploy the node** before the label takes effect.
- In UPI clusters, prefer setting labels **within the `MachineSet` object** — the machine/cluster API can silently override labels applied directly to a node.
- Node pools ≠ `NodePool` API object in standard clusters — that's an HCP-only resource. Don't confuse the two on the exam.
- ROSA / managed clusters expose **machine pools** (not raw `MachineSet`) — the underlying `MachineSet` is protected from direct edits there.

## Provisioning Context (brief)

- **UPI** (user-provisioned infra): manual steps — update ignition file → install RHCOS → add to LB → approve CSRs.
- **IPI** (installer-provisioned infra): scale by editing `MachineSet` replica count; cloud provider handles provisioning automatically (supports autoscaling).
