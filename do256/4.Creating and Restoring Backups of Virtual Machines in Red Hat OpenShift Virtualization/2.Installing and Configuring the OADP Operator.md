# 4.3 Installing and Configuring the OADP Operator

- Needs `cluster-admin` to configure; backups/restores need admin in the OADP namespace (default `openshift-adp`).
- Needs object storage: any S3-compatible store (MinIO, ODF), AWS, Azure, GCP, IBM COS.
  - ODF offers NooBaa MCG and Ceph RGW; both work with the `aws` plug-in.
  - An `ObjectBucketClaim` (OBC) requests a bucket; ODF creates a secret and config map with the same name holding access details.
  - A `.svc` endpoint is only reachable inside the cluster; use the `s3` route in `openshift-storage` for an external URL.
- CSI snapshots: a `VolumeSnapshotClass` driver must match the storage class provisioner. No snapshot support (e.g. NFS) means use file-system backup.
- Install the operator from OperatorHub or with `oc`.
- Create the credentials secret first, or the DPA fails. Default name `cloud-credentials`, key `cloud`; its profile name must match the backup location config.
- Create the DPA in the operator namespace (YAML view gives all options). Key fields:
  - `nodeAgent.enable: true` and `uploaderType: kopia` for Data Mover.
  - `defaultPlugins`: `aws`, `openshift`, `csi`, `kubevirt`.
  - `defaultSnapshotMoveData: true` sends snapshots to object storage.
  - `backupLocations`: provider, `s3Url`, credential, `bucket`, optional `prefix` and `caCert`, `default: true`.
- Wait for DPA condition `Reconciled`.
- Label one snapshot class per driver with `velero.io/csi-volumesnapshot-class=true`.
- Check: `openshift-adp-controller-manager` and `velero` deployments, `node-agent` daemon set.
- `BackupStorageLocation` should be `Available`; if `Unavailable`, read its status message (validated about every minute, see `lastValidationTime`).
- Test the bucket with `aws s3 ls --endpoint-url <url>` or `s3cmd`.
