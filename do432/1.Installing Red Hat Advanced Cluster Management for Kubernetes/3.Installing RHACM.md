# 1.5 Installing RHACM

- Install the **RHACM operator** via OperatorHub (connected) or a local image endpoint (disconnected).
- **Prerequisites**: an OpenShift/K8s cluster, a supported browser, hub↔managed-cluster network connectivity. Resource needs scale with cluster count, platform, storage/network speed, and app count.
- **Install steps**: pick update channel → recommended namespace `open-cluster-management` → choose Manual or Automatic update approval → Install.
- After the operator installs, you must create the **MultiClusterHub** CR to actually deploy RHACM services (`apiVersion: operator.open-cluster-management.io/v1`). Status goes `Phase: Installing` → `Phase: Running`.
- View the RHACM console by setting the cluster switcher to **All Clusters**.
- **Common install issues**: operator stuck `Pending` (no internet/images unavailable/insufficient node resources), or leftover artifacts from a prior failed install/uninstall — cleaned up via a documented `oc delete` script targeting the old namespace, CRDs, and webhooks.
