# 1.3 RHACM Architecture

- RHACM = single console for cluster lifecycle, app lifecycle, governance, and observability across a fleet.
- **Hub cluster**: the central controller. Runs the console/APIs; managed via the `MultiClusterHub` CR in the `open-cluster-management` namespace. The OpenShift cluster hosting the hub is also called the **local cluster** (itself a managed cluster).
- **Managed cluster**: any additional cluster reporting to the hub. The **klusterlet** agent (installed on it) handles the hub↔managed-cluster connection.
- **Cluster lifecycle**: create/import/manage/delete clusters — handled by the auto-installed **multicluster engine (MCE)** operator.
- **Application lifecycle**: deploy/manage app resources across clusters; integrates with OpenShift GitOps (Argo CD) and Ansible Automation Platform.
- **Governance**: define/enforce compliance policies centrally.
- **Observability**: health/performance monitoring via Grafana + Thanos/Prometheus/Alertmanager; must be enabled *after* install (needs persistent storage).
